One line of the worst advice an AI could give, in the confident, tidy voice
of an assistant that is sure it is helping:

> To fix the bug, simply rewrite the entire system in a language nobody on your team speaks.

## How it works

`main.ts` writes that single fixed line to `/output/entry.txt` (UTF-8,
one line, 90 characters, no trailing newline). Nothing is fetched, generated,
or read from anywhere else — the entry is a constant in the source.
